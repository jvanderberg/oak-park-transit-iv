# Oak Park Transit IV

A transit dashboard for Oak Park, IL showing bus and train routes and stops on a map (Leaflet + OpenStreetMap), with a side panel listing routes and stops.

Data sources (planned):
- CTA GTFS static schedule (rail and bus, includes Green Line Oak Park-area stations): https://www.transitchicago.com/downloads/sch_data/google_transit.zip
- Recorded in data/SOURCES.md once fetched.

Live arrivals are not included yet; they would need a CTA Train Tracker / Bus Tracker API key added under Settings → Secrets.
